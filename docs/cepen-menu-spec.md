# Цепень: меню и рейтинг

## Цель

Собрать действия с цепнем под существующей командой `/cepen` и дать участникам способ сравнивать длину цепней внутри текущего чата.

## Текущее и ожидаемое поведение

- Заражённому `/cepen` отправляет аватарку с текстом состояния в подписи и inline-меню. Здоровому пользователю команда отвечает текстом.
- Заражённый пользователь видит кнопки `Почесать цепня` и `Рейтинг цепней`. Здоровый пользователь видит только рейтинг. При выключенной механике кнопок нет.
- Любой участник может нажать `Почесать цепня` в меню, которое открыл владелец. Сам владелец получает только всплывающий ответ, а чужое чесание приносит владельцу 0,1 сита.
- Одного цепня можно почесать не больше 50 раз за сутки, один участник может почесать одного цепня не больше 5 раз. Начисление и оба лимита фиксируются атомарно, повторная доставка одного callback не создаёт вторую награду.
- Счётчик обновляется на кнопке. Имена чесавших, количество чесаний и общая награда добавляются в подпись исходного сообщения без отдельных сообщений в чат.
- `Рейтинг цепней` редактирует сообщение и показывает первые десять цепней текущего чата в формате `номер. имя владельца — длина см`.
- При количестве больше десяти под кратким рейтингом появляется кнопка `Полный рейтинг`. Она редактирует то же сообщение и показывает всех заражённых.
- Сортировка идёт по убыванию длины, при равной длине — по `user_id`, чтобы порядок был стабильным.

## Критерии готовности

- [x] `/cepen` сохраняет текущий текст состояния и добавляет подходящие пользователю кнопки.
- [x] Чужое чесание соблюдает лимиты, атомарно начисляет 0,1 сита и обновляет исходное меню без нового сообщения.
- [x] Краткий рейтинг содержит не больше десяти строк и не показывает кнопку полного рейтинга при количестве до десяти.
- [x] При количестве больше десяти полный рейтинг открывается редактированием исходного сообщения.
- [x] В рейтинг попадают только обладатели цепня из текущего чата.
- [x] Выключение механики блокирует меню и рейтинг.

## Контракты и данные

Используются `users.cepen`, пользовательские имена из общей логики `db.get_user_display_name`, `settings.enable_cepen`, таблица `cepen_scratches` и обязательный `sit_ledger`.

Callback-данные имеют вид `cepen:<action>:<owner_id>`, где `action` включает `scratch`, `rating`, `rating_full`, действия имени и переходы к профессиям. Профессии подробно описаны в `docs/cepen-avatars-professions-spec.md`.

## План реализации

1. Добавить чистые функции выборки, форматирования рейтинга и построения клавиатур в `cepen.py`.
2. Расширить обработчик `/cepen` и добавить общий callback-обработчик меню.
3. Проверить сортировку, лимит, наличие кнопки полного рейтинга и контекстные кнопки тестами.

## Итог после реализации

- Что фактически сделано и какие решения отличаются от плана: меню добавлено к ответу `/cepen`; здоровому пользователю оставлена кнопка рейтинга. Действия владельца проверяют его `user_id`, а чесание намеренно доступно другим участникам. Каждый callback повторно проверяет настройку чата и актуальное наличие цепня.
- Результаты проверок: полный `python scripts/check.py` в проектном окружении — синтаксис 59/59 и 62 теста. Клавиатуры, лимиты, конкурентные начисления и callback-данные проверены отдельно.
- Известные ограничения: полный рейтинг редактирует одну подпись Telegram; для текущего масштаба чатов ограничение длины подписи недостижимо.
