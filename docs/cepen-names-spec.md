# Имена цепней

## Цель

Дать владельцу возможность назвать своего цепня и использовать это имя во всех персональных сообщениях механики, чтобы паразит воспринимался отдельным персонажем.

## Текущее и ожидаемое поведение

- Сейчас цепень хранит только длину и во всех сообщениях называется просто цепнем.
- После изменения заражённый пользователь видит в `/cepen` кнопку `Дать имя цепню` или `Изменить имя цепня`.
- Кнопка запускает FSM и спрашивает имя. При переименовании дополнительно показывается подсказка `Введите - чтобы удалить имя`.
- Одиночные символы `-`, `‐`, `‑`, `‒`, `–`, `—`, `―`, `−`, `﹣` и `－` удаляют имя. Пробелы вокруг символа игнорируются.
- Имя очищается от лишних пробелов и ограничено 32 символами. Пустой или слишком длинный ввод не завершает FSM и просит повторить попытку.
- Имя используется в `/cepen`, рейтинге, почесывании, ежедневной подписи, заражении от именованного источника, вечернем росте, анабиозе, `/flood`, магазине и сообщениях лечения.
- Если имя отсутствует, сохраняются прежние безымянные формулировки.
- Полное лечение удаляет имя. Частичное лечение и выключение механики его сохраняют.

## Критерии готовности

- [x] Миграция старой базы и повторная инициализация добавляют `users.cepen_name` без потери данных.
- [x] FSM позволяет задать и изменить имя только владельцу существующего цепня.
- [x] Все заявленные варианты дефиса, тире и минуса удаляют имя.
- [x] Имя безопасно экранируется в HTML-сообщениях.
- [x] Ежедневная подпись имеет вид `– твой цепень Виталик ❤️`, а без имени остаётся прежней.
- [x] Рейтинг и все персональные сообщения механики используют имя при его наличии.
- [x] Полное лечение очищает имя, частичное лечение и выключение чата сохраняют.

## Контракты и данные

- `users.cepen_name TEXT` — пользовательское имя цепня в рамках пары `(user_id, chat_id)`; `NULL` и пустая строка означают отсутствие имени.
- Максимальная длина после нормализации — 32 символа.
- Имя хранится как обычный текст. Экранирование выполняется при формировании HTML-сообщения.

5. Добавить тесты миграции, ввода, удаления, лечения и основных сообщений.
