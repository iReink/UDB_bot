# Цепень: чесание другими участниками

## Цель

Чесание цепня должно стать социальной активностью и небольшим источником сита для его владельца. Владелец публикует доступную другим участникам кнопку через `/cepen`, а друзья помогают ему оплачивать растущие расходы на цепня.

Основной риск — повторные и одновременные нажатия. Лимиты и награда должны фиксироваться одной атомарной операцией, чтобы конкурентные запросы не создавали лишний сит и не превышали суточные ограничения.

## Текущее и ожидаемое поведение

- Сейчас кнопку может нажать только владелец, после чего бот отправляет отдельное сообщение без награды.
- После изменения любой участник чата может почесать цепня из сообщения `/cepen`, созданного его владельцем.
- Успешное чужое чесание начисляет владельцу `0.1` сита и учитывается в суточной истории.
- За серверные сутки один пользователь может почесать одного цепня не больше 5 раз, а всего одного цепня можно почесать не больше 50 раз.
- Собственное чесание остаётся шуточным действием без награды и не расходует лимиты.
- Бот не отправляет новое сообщение на каждое нажатие. Он показывает короткое уведомление на кнопке и обновляет исходное сообщение: счётчик, список чесавших и сумму награды.
- Повторная доставка Telegram одного и того же callback не начисляет награду повторно.
- Устаревшая кнопка проверяется по актуальному состоянию БД; показанный на ней счётчик обновляется после нажатия.

## Критерии готовности

- [x] Чужое успешное нажатие увеличивает баланс владельца и создаёт запись `sit_ledger` на `0.1` сита.
- [x] Шестое нажатие одного участника и 51-е суммарное нажатие не начисляют сит.
- [x] Повтор одного callback и конкурентные нажатия не обходят лимиты.
- [x] Кнопка показывает имя цепня, если оно есть, и счётчик `[N/50]`.
- [x] В конце `/cepen` перечислены чесавшие сегодня, количество их нажатий и общая награда.
- [x] Собственное чесание не меняет баланс, историю и лимиты.
- [x] `/cepen` не показывает баланс и упоминает член только при ожидаемом фактическом росте.
- [x] Справка `/cepen` и общая справка используют новый короткий текст.

## Контракты и данные

Новая таблица `cepen_scratches` хранит одно успешное чужое чесание на строку. `callback_query_id` — первичный ключ для идемпотентности. Дата фиксируется по серверному календарю; индексы по владельцу и чесавшему поддерживают проверку обоих лимитов.

Проверка состояния цепня, лимитов, запись события и `db.apply_sit_change` выполняются в одной транзакции `BEGIN IMMEDIATE`. Схема описана в `STATS_DB_SCHEMA.md`; миграция повторяема и не меняет существующие записи.

## План реализации

1. Добавить повторяемую миграцию и документировать таблицу.
2. Реализовать атомарную доменную операцию чесания и получение суточного итога.
3. Обновить текст `/cepen`, клавиатуру и callback без новых сообщений в чат.
4. Обновить общую справку, архитектурную карту и тесты миграции, экономики, лимитов и конкурентности.
