## Цель

Добавить Карину и Виталия Хемуля в существующую механику брака, чтобы механики случайного сосания и выбора партнёра для шпёха связывали их только друг с другом.

## Текущее и ожидаемое поведение

- Сейчас: `user_id=1235654176` и `user_id=765591886` не входят в список супругов и могут получать других партнёров по общим правилам.
- После изменения: они считаются супругами; каждый из них может быть выбран только для второго, а остальные игроки не могут получить ни одного из них как партнёра.
- Если супруг не входит в список доступных активных партнёров, действие не подменяет его другим пользователем.

## Критерии готовности

- [x] Карина получает Виталия Хемуля, если он доступен среди активных пользователей.
- [x] Виталий Хемуль получает Карину, если она доступна среди активных пользователей.
- [x] Посторонний пользователь не может получить Карину или Виталия Хемуля.
- [x] При недоступном супруге женатому пользователю не выбирается другой партнёр.

## Контракты и данные

Используется существующий список `MARRIED_PAIRS` в `sosalsa.py`. Схема БД не меняется; правило действует во всех чатах, как и существующие браки.

## План реализации

1. Добавить пару `(1235654176, 765591886)` в `MARRIED_PAIRS`.
2. Добавить регрессионные тесты фильтра случайных активных партнёров.
3. Запустить проверки и развернуть изменение.

## Итог после реализации

- Что фактически сделано: пара добавлена в общий список браков; тесты подтверждают взаимный выбор, недоступность супругов постороннему игроку и отсутствие замены при неактивном супруге.
- Результаты проверок: целевой `test_married_pairs.py` — 2 теста; полный `python scripts/check.py` — синтаксис 57/57 и 54 теста. Все проверки прошли.
- Известные ограничения: существующая механика брака глобальна по `user_id`, поэтому ограничение действует во всех общих чатах пары.
