# ИИ, настройки, память и поиск

## Источники и очереди ИИ {#sources}
Настройки «Источник ИИ»: только внешний API, только локальная модель, локальная с резервом API, API с резервом локальной, ответы выключены. По умолчанию локальная. Реальная доступность источников и квот определяет исполнителя; очередь сохраняет задачу и аренду. Повтор результата не должен отправлять второй ответ. Воркеры ожидают работу до 25 секунд через веб-координатор; после записи задачи локальный сокет передаёт имя очереди. Потерянное уведомление восстанавливается общей проверкой готовности раз в секунду. Старые запросы next без ожидания поддерживаются. Быстрые задачи и фотоистории обслуживаются отдельно. Типизатор, SQL, анализ, ответ, поиск и фоновые задачи — разные этапы. Выключенный источник нельзя обходить запросом о правилах.

## Саммери и профиль {#summary}
/summary создаёт свежий блок от конца последнего до текущего момента, если прошёл час и нет выполняющегося блока. При подготовке нового блока кнопка задерживается 5 секунд; иначе выдаётся сразу. Mini App открывает свежий саммери нужного чата, позволяет листать и переходить к первому ближайшему сообщению периода. При запуске миниапп запрашивает максимальную высоту, на современных мобильных клиентах — полноэкранный режим; при отказе остаётся раскрытое окно. Кнопки и дата закреплены внутри видимой области с учётом безопасных отступов. Соседние блоки видны полупрозрачно, длинный активный текст прокручивается пальцем. Время блоков и сообщений местное +05:00, даты AI-задач UTC. Профили обновляются фоново и содержат предположения по сохранённой переписке, а не подтверждённые биографические факты.

## Историческая память RAG {#memory}
История индексируется Google Embedding и хранится в Qdrant; сама Qdrant не векторизует текст. При response поиск дополняет короткий контекст и саммери релевантными выдержками своего чата до текущего сообщения. Дедлайн 5 секунд, максимум 4 фрагмента и 1200 токенов. Не вся история передаётся LLM сразу. Точные расчёты выполняет SQL. Первичная и последующая индексация выполняются только в 04:00–07:00 по Екатеринбургу. В начале фиксируется граница событий: более поздние изменения остаются на следующую ночь. Незавершённый проход продолжается после перезапуска или следующей ночью, подтверждённые векторы используются повторно. Изменённые и удалённые источники проверяются перед выдачей круглосуточно. Прогресс обновляется транзакционными счётчиками; полная сверка выполняется раз в неделю ночью. Дашборд показывает ожидание ночи, обработку, перенос продолжения и границу событий.

## Веб-поиск и карты {#grounding}
Веб-поиск предназначен для актуальных внешних фактов, карты — для мест и маршрутов. Это инструменты моделей, с собственными квотами и совместимостью. Внутренние гейзеры и банк не относятся к Google Maps. При нехватке места нужно уточнить город; модель не должна угадывать местоположение из персональных данных. Результаты оформляются в Telegram, а технические источники сохраняются отдельно. Ошибка инструмента не подтверждает факт, найденный моделью.

## Справочник правил и SQL {#mechanics}
Задачи фотоисторий используют ту же устойчивую очередь; подробнее описаны ниже.
Задача mechanics объясняет проверенные правила без чтения личного состояния. Ей задаётся цель отвечать до 3000 символов; заголовки, выделение и списки преобразуются в формат Telegram. SQL и анализ получают относящиеся к вопросу разделы; справка не доказывает текущее богатство, кредит или рост конкретного человека. Документы имеют ревизии, устаревшие исключаются. Пользовательский SQL не читает служебные таблицы справочника в обход проверки актуальности; правила доступны через подготовленный контекст. При отсутствии данных ответ признаёт ограничение. Справочник и история переписки находятся в отдельных коллекциях. Семантический порог справки — 0,65; подготовка ограничена пятью секундами и четырьмя разделами, 2000 токенами и 8000 символами. При отказе внешних сервисов используется актуальный лексический поиск.


## Истории по фотографиям в личке {#photo-story}
Отправленное в личку фото или Telegram-альбом без обращения к боту и без творческой просьбы в подписи запускает экспериментальный рассказ. Сначала подборка собирается после трёх секунд тишины и выбирается сценарий; затем очередь истории собирает до десяти кадров ещё после трёх секунд тишины. Отдельные фотографии образуют отдельные истории. Подпись помогает понять сюжет. Обращение к боту в подписи проходит типизацию; просьба создать или изменить картинку запускает imagegen вместо истории. Анализ истории выполняется совместно по кадрам, затем текстовая модель собирает короткую историю с доброжелательным юмором и лёгким сарказмом. Бот должен отделять видимое от предположений и не угадывать личности или события за кадром. До трёх незавершённых историй на пользователя.

Эксперимент передаёт фотографии внешнему Google API: фото обрабатывает цепочка Flash 3.8 → 3.7 → 3.6 → 3.5 → 3 preview, окончательный текст — разговорная цепочка. При исчерпании лимитов запрос ждёт восстановления. Личный сценарий использует внешний API независимо от обычного локального режима; явное отключение ИИ действует. Сжатые изображения обрабатываются в памяти, постоянные серверные копии не создаются. ID файлов, подписи и текст сохраняются в служебной очереди. В группах эксперимент не запускается. Для фотоисторий правило общения с создателем не передаётся ни при анализе, ни при сборке рассказа.

## Журнал ИИ-задач {#task-dashboard}
Административный дашборд показывает дату, чат, тип задачи, контекст, модель, ответ и результат. В кратком ответе типизации отображается русское название выбранного типа; наведение показывает английский идентификатор. Для профиля отображается имя из сохранённого результата или снимка задачи. Для общения отображается текст ответа без технической обёртки API. Нажатие открывает подробности, включая попытки вызова; окно профиля сохраняет просмотр истории. Рейтинг моделей сначала показывает пять наиболее используемых; «ещё» раскрывает полный список. Раскрытие сохраняется при автоматическом обновлении. Счётчики учитывают все модели независимо от раскрытия.
