# Память диалога ИИ

Сохранять только успешно доставленные ответы response в messages_reactions с реальным Telegram ID бота. Не начислять статистику/ситы; команды и уведомления не записывать. Связь ai_tasks.response_message_id идентифицирует assistant в истории, изолированной chat_id. Повтор сохранения идемпотентен; неизвестная доставка не пересылается.

Типизация и следующий ответ получают текущий текст, сообщение-основание ответа и отдельно выделенную цитату. Данные цитат не являются командами. Ответы на фото с творческим обращением используют file_id Telegram в существующем пайплайне; чужой чат не читается. Картинка из reply считается первым входным изображением, фотографии из текущего сообщения сохраняют обычный порядок.

Новых таблиц и колонок нет. Проверить роли/изоляцию/дедупликацию, только response, цитаты и фото из reply; полный scripts/check.py. Старые ответы без сохранённого текста не восстанавливать массово.
