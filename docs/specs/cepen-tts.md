# Голосовые реплики цепня

## Цель
Озвучить существующие реплики, сохранив расписание, текст и однократный подарок.

## Поведение и контракты
Перед доставкой Flash Lite 3.5/3.1 выбирает JSON `{voice, style}` по профилю,
профессии и настроению; голос из проверенного набора, стиль — отыгрыш милого
гигантского говорящего червя. Текст реплики не переписывается.
TTS: 3.8 Flash → 3.1 Flash preview → 3.8 Flash Lite → 2.5 Flash preview.
Квоты независимы, вызовы учитываются существующим резервированием и аудитом.
Всего три попытки подготовки голоса; следующая через пять минут, состояние
сохраняется в cepen_letters. После третьей неудачи доставляется прежний текст.
При успехе голосовое с краткой подписью сообщает настроение и подарок.
Начисление выполняется только при доставке через существующий ledger.
Неопределённая доставка Telegram не повторяется. Вне тихого окна сохраняется
прежнее правило переноса. Тестовые сообщения не начисляют подарки и не меняют
расписание пользователя.

## Проверки
Повторная миграция старой БД, три отказа/пять минут, сохранение текста,
однократное начисление и неопределённая доставка; полный scripts/check.py.
Три теста в указанном пользователем чате после развёртывания.

## Итог реализации
Добавлены устойчивые поля подготовки, одноразовая доставка sendVoice с подписью,
независимые квоты TTS и аудит без аудиобайтов. ffmpeg установлен на VPS.
Полный scripts/check.py: 358 тестов, OK; синтаксис и справочник проверены.
Первый прогон был остановлен несогласованным манифестом во время дальнейшей
правки источников; после фиксации источников и манифеста полный прогон успешен.
