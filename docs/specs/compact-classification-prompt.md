# Компактный промпт типизации

## Цель
Сократить служебный контекст типизатора, исключив правило общения с создателем.

## Поведение
Новые задачи типизации создаются без creator-policy. При выдаче воркеру старой задачи удаляется только служебный префикс; правило не добавляется повторно. Системная инструкция типизации остаётся пустой. Пользовательский текст, список типов и критерии выбора сохраняются. Разговорные ответы сохраняют правило общения с создателем.

## Проверка
Проверить новый промпт при настроенном creator ID и выдачу старого промпта воркеру. Полный scripts/check.py, публикация справки и проверка рабочего сервера. Схема БД не меняется.

## Итог
Удалён декоратор creator-policy из build_type_check_prompt; runtime исключает типизацию из повторного добавления правила и удаляет старый префикс. Развёрнуто на сервере, веб и бот перезапущены. Пример: 4065 → 3099 символов. Полный scripts/check.py: 307 тестов OK; после добавления сценария старой задачи отдельно test_ai_runtime.py: 55 тестов OK.
