# Снижение CPU фоновых ИИ-процессов

Цель: приблизить среднесуточный суммарный CPU VPS к 8% ядра без удаления функций. Реализация по этапам: одноразовая инициализация схемы; ночной RAG 04:00–07:00 и счётчики; уведомления/ожидание очередей; ограниченные повторы; кеши и фоновые расписания. Поиск для ответа сохраняет дедлайн 5 секунд, саммари и текущие фотоистории сохраняют сроки.

SQLite остаётся источником истины. Уведомления лишь пробуждают обработчики; потеря уведомления, перезапуск и истечение аренды не теряют задачи. Суточные квоты, минутные ограничения и транспортные ошибки различаются. Пользовательские задачи приоритетнее фоновых.

После каждого этапа: профильные тесты, полный scripts/check.py, согласованный деплой, минутный замер приращения CPU служб и суммарного CPU/steal. Итоговое сравнение — за 24 часа с объёмами сообщений, запросов и индексации. Схемы проверять на временных базах, дополнительный backup не создавать. Обновлять публичную справку и манифест по фактически завершённым этапам.
