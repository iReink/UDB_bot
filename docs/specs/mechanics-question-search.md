# Поиск конкретных ответов по механикам

## Цель и контракт
Отвечать непосредственно на вопрос по актуальной проверенной справке. Дополнить заражение цепнем, пользовательские названия групповой мастурбации и формулу ставки вклада после сверки кода. Общий обзор только по запросу; личные текущие значения требуют БД.

## Реализация
Локальный поиск по словоформам и синонимам каталога, один API-вызов уточнения (до 8 секунд), повторный поиск и ранжирование конкретных разделов. Общий дедлайн mechanics 15 секунд; SQL остаётся 5 секунд. Не более 2000 токенов/8000 символов контекста. JSON уточнения содержит тему, поисковые фразы и необходимые факты, но не правила. При сбое использовать исходный поиск. Один поток RAG не берёт mechanics и обслуживает короткую подготовку. Вызов учитывается существующими квотами и журналом. Схема и публичный API не меняются; существующий триггер переопределяется идемпотентно при старте.

## Проверки и публикация
Временная БД: три исходных вопроса и перефразировки, ошибки/таймаут/JSON, бюджет контекста, устаревшие ревизии, раздельные дедлайны. Полный check.py, живой прогон без Telegram-публикации. Публикация кода и справки через sync_mechanics, перезапуск потребителей, отдельный коммит и push без дополнительного бэкапа.

## Результат проверки 2026-10-13
Полный scripts/check.py: 342 теста, OK. Новые восемь тестов проверяют шесть формулировок, fallback, JSON, актуальность, бюджет и отдельный быстрый поток. Живой прогон без Telegram: все три исходных вопроса классифицированы как mechanics; получены конкретные ответы о заражении, сценарии группового события и зависимости ставки. Первые успешные ответы — Gemini 3.1 Flash-Lite, банковский ответ — доступный Groq GPT-OSS-120B через существующий адаптер, без изменения рабочего пула. Поиск занял 3,09 / 4,32 / 9,23 секунды; банковский контекст содержит только deposit-rate. Квоты и аудит вызовов сохранены обычным путём. Первоначальные прогоны встречали HTTP 503, ReadTimeout и невалидный JSON; fallback проверен, это не гарантирует постоянной доступности API.
