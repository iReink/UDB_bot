# Явные пожелания пользователя

## Поведение
Отдельная память по (chat_id,user_id), не часть автоматически обновляемого
профиля. Только прямые обращения владельца к боту, без пересылок и исполнения
цитируемого текста. Поддерживаются обращение, ты/вы, краткость, капс, эмодзи,
мягкость юмора и запрет шуток на фиксированные личные темы. Независимые поля
накапливаются, меняется только конфликтующий пункт. Есть просмотр, сброс всех
пожеланий и отмена отдельного пункта. Сохраняются только проверенные значения;
диагнозы и исходный текст просьбы не копируются в эту память.

## Границы
Не меняет аккаунт, авторизацию, факты, игровые правила или чужие пожелания.
Произвольные инструкции не сохраняются. Неподдерживаемая просьба уточняется,
опасная инструкция отклоняется. Обновление/подтверждение идемпотентны по
Telegram chat/message_id; повтор неизвестной доставки подтверждения запрещён.
Никакого дополнительного вызова ИИ для сохранения; узкий локальный разбор.

## Реализация и проверка
ai_user_preferences и ai_preference_requests, повторяемое создание при старте.
Таблицы запрещены для text-to-SQL; в response prompt добавляется ограниченный
блок собственных предпочтений как данных, ниже правил безопасности/доступа.
Существующие профили, настройки и другие типы задач сохраняют поведение.
Проверки: накопление имени и капса, конфликт/отмена одного поля, изоляция
чата/владельца, отказ инъекций, цитат и пересылок, повтор update, сохранение
после обновления профиля, присутствие блока при сокращении prompt; полный check.
