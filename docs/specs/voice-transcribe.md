# Распознавание голосовых

## Цель и поведение
Каждое входящее voice от человека ставится в устойчивую очередь. Gemini 3.5
Transcribe возвращает исходный текст без пересказа. Начальное отдельное слово
«бот» (без учёта регистра, с пробелом/пунктуацией) удаляется для запроса;
такое сообщение или reply именно этому боту идёт в существующую типизацию.
Остальные получают только текстовую расшифровку в ответ на голосовое, без
случайной ИИ-реакции. При отключённом ИИ остаётся только расшифровка.
Reply/quote и изображения из reply сохраняются для существующего пайплайна.

## Данные и отказы
ai_voice_transcripts хранит идентификатор сообщения, Telegram metadata, статус,
текст, число попыток, retry_at и ошибку. Байты аудио в БД/аудит не попадают.
Служебная таблица запрещена для text-to-SQL, сохраняются ограничения чатов.
Расшифровка обновляет существующее messages_reactions того же автора/чата;
статистика сообщений не начисляется повторно. Миграция повторяема.
Worker пробуждается событием; при пустой очереди нет активного опроса.
После рестарта подготовленные тексты используются повторно. Начатая отправка
не повторяется при неопределённом Telegram-ответе. Типизация идемпотентна по
chat_id/message_id. Суточная квота сообщает об исчерпании, минутная откладывает
запрос; транспорт имеет один отложенный повтор. Лимиты: 3 RPM, 25 RPD, 10k TPM;
аудио до 14 MB (в base64 вместе с JSON должно поместиться в 20 MB запроса).
Длительность ограничена минутным токенным бюджетом: оценка 32 токена/секунда,
примерно пять минут при текущем TPM. Слишком длинная запись получает объяснение.

## Проверка
Обращение со слова «бот», «ботаника» и слово в середине; reply своему/чужому
боту, обычная расшифровка, отключённый ИИ, длинный текст, квоты, повтор update,
рестарт и неизвестная доставка. Проверить аудио на реальной модели без отправки
посторонних тестовых сообщений. Полный scripts/check.py, справка и манифест.

## Итог реализации
Очередь и восстановление реализованы; metadata недоступны для text-to-SQL,
голосовые ботов (в том числе цепня) не ставятся в очередь. Все 374 теста полного
scripts/check.py прошли, синтаксис 146 файлов и публичная справка проверены.
Реальная модель распознала русскую OGG-запись длительностью 28 секунд; результат
не публиковался в Telegram. Токены и запрос учтены в общем журнале модели.
Существующее ограничение лички сохранено: неподдерживаемое обращение получает
расшифровку, вместо молчаливого пропуска. В группах действует обычная типизация.
